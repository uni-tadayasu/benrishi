# 弁理士合格ラボ

弁理士試験の学習に使う、ブラウザで動く静的な学習サイトです。条文を読む、要点を確認する、問題を解く、復習する、文章を聞く、という学習を一つの画面から進められます。合格を保証するサービスではありません。

- 公開サイト：<https://uni-tadayasu.github.io/benrishi/>
- リポジトリ：<https://github.com/uni-tadayasu/benrishi>
- 法令の収録基準日：**2026年11月25日**。条約資料は資料ごとの版・言語・注意書きを確認してください。
- 公開方式：**GitHub Pages、`main` ブランチ、`/ (root)`**。公開用の `index.html` はリポジトリ直下に置きます。

## できること

- 法律・条文ライブラリの全文検索、条文・附則・別表の閲覧、図や様式のPDF表示。
- 原文、要点、詳細を切り替えた学習。主要条文の個別解説、関連する根拠条文への移動。
- 短答トレーニング、選択肢ごとの解説、間違えた問題の復習、学習記録。
- 論文の答案作成、口述の練習、学習プラン、重要事項の保存。
- 文章の用語を調べる用語モード、見出し・読みでの辞典検索、説明・定義原文の読み上げ。
- 条文のマーカー、書き込み、ブックマーク。学習データのJSONバックアップと復元。
- 音声の速度・声の選択、法律用語の読み補正、個人用の読み辞書、連続読み上げ、1件・全件のループ再生。
- 全教材を端末に一括保存した後のオフライン利用。

## 実際の収録範囲

収録対象は、各マニフェストに列挙した有限の資料です。「関連する全法令」「全条文に専門的な個別解説」「全ての日本語の意味」の網羅を意味しません。

| 内容 | 収録分と扱い |
| --- | --- |
| 国内法令 | **42法令**。本則・附則を合わせて6,639条文区分、別表等の補助区分2,260件。e-Gov法令XMLから抽出。削除条文や経過措置も保持しています。 |
| 図・画像様式 | **405点のPDF**。12個の無圧縮ZIPにまとめ、大きいZIPは公開用に2MiBずつ分割しています。画像内の文字がすべて検索・読み上げできるという意味ではありません。 |
| 条約・関連資料 | **12資料**。日本語8資料、英語4資料。PDFは物理ページ単位、HTML由来の本文は条文単位で表示します。 |
| 個別の学習解説 | **55条文**。要約・詳細・事例・注意点を独自に執筆。それ以外の条文では項別構造の表示と先頭文等の抽出を使用します。 |
| 短答演習 | **60問の独自学習問題**。特許庁の過去問題そのものではありません。 |
| 用語辞典 | 法令から抽出した**1,042語・略称／1,806件の出典**と、`glossary-study.js` に収録した**250語の学習説明**（読み・要約・詳細）。統合後は**1,242語**です。画面の収録数は重複を統合した件数です。未収録の言葉は未収録と表示します。 |

42法令には、特許・実用新案・意匠・商標の各法と施行令・施行規則・登録関係の令・規則、工業所有権の手続特例、手数料、国際出願の国内法、著作権、不正競争、弁理士法、民法、民事訴訟・執行・保全、行政不服審査・行政事件訴訟・行政手続の関連法令を含みます。正式なタイトル、法令ID、改正ID、件数、出典は [法令マニフェスト](law-corpus/manifest.json) と [取得用カタログ](scripts/law-catalog.json) にあります。

条約資料の一覧と版情報は [条約マニフェスト](treaty-corpus/manifest.json) にあります。**パリ条約の日本語資料は1967年改正の旧版参考、マドリッド議定書の日本語資料は1989年採択の旧版参考**です。旧版資料は区別して表示します。マドリッド議定書・規則等の現行学習用資料は別に英語版を収録しています。PCT日本語版には仮訳の注意書きがあります。TLTの出願様式や、WCT・WPPTの掲載HTMLに付属しない合意声明はこの収録物に含まれません。

## オフライン利用と読み上げ

1. オンラインでサイトを開き、「設定・オフライン」から全教材の一括保存を実行します。
2. 保存完了の表示を確認します。ファイルのサイズとSHA-256を確認してから保存状態を記録します。教材本体の合計はおおむね80MBです。対応ブラウザでは端末保存時に自動でgzip圧縮して容量を節約し、表示・読み上げやSHA-256検証の前に元の内容へ戻します。正確な容量は画面と [保存対象一覧](offline-assets.json) に記載されます。
3. 同じ端末・同じブラウザで開き直します。Service WorkerとCache Storageが使えるHTTPS環境が必要です。開発時は `localhost` も利用できます。
4. 機内モード等で条文、PDF、問題、用語辞典、保存済みの書き込みを確認します。

ブラウザがサイトデータを削除した場合や、別の端末・ブラウザを使う場合は、再度保存してください。学習履歴・答案・マーカー等はブラウザ内に保存されます。端末間の自動同期はありません。移行や保存領域の削除に備える場合は、設定画面からバックアップを保存できます。

読み上げには端末・ブラウザの音声合成機能を使います。**通信なしで読み上げるには、その言語の端末内音声がインストールされ、ブラウザから利用できることが必要です。** 日本語資料には日本語音声、英語資料には英語音声を使用します。声の提供元が通信を必要とする場合は完全オフラインでは使えません。読み辞書は誤読を減らすための補正であり、全ての語・固有名詞・数詞の読みの正しさを保証しません。表示中の公式条文は音声補正で書き換えません。

公式サイトへの外部リンク、試験日程や法改正の確認、教材の更新には通信が必要です。保存済み資料は自動的に最新法令へ置き換わりません。

## ローカルで開く

アプリの実行にnpmビルドやデータベースは不要です。公開用ファイルのあるディレクトリで、例えば次のようにHTTPサーバーを起動します。

```bash
python3 -m http.server 4173 --directory .
```

`http://localhost:4173/` を開きます。`file://` でHTMLを直接開くと、データ取得やオフライン機能を正しく確認できません。編集用の作業ディレクトリに `dist/` がある場合は `--directory dist` を指定してください。公開するのは `dist/` の中身であり、GitHub Pages側の公開先はリポジトリ直下です。

## データの再取得・再生成

`scripts/` は公開済みデータの由来を追い、別の作業ディレクトリに再生成するための補助スクリプトです。**アプリ画面や55件の解説、60問の問題、独自の学習用語説明を自動生成するものではありません。** それらはレビューしたJavaScriptファイルが編集元です。

Python 3.10以上を使用します。法令・図表・辞典・検証の処理は標準ライブラリで動きます。条約のPDFから本文を再抽出する場合だけ、`pypdf` とPopplerの `pdftotext` が必要です。

```bash
python3 -m pip install -r scripts/requirements.txt
```

`pdftotext` は利用環境のパッケージ管理で導入してください。作成時に使用したPDF関連の版はPoppler `25.03.0` と `pypdf 6.21.4` です。各スクリプトの `--help` で引数を確認できます。以下はGitHubの公開ファイルをリポジトリ直下に置いた状態で、そこから実行する例です。出力先は `work/` に分けています。

### 1. 国内42法令、図・様式

```bash
python3 scripts/fetch-laws.py --catalog scripts/law-catalog.json --as-of 2026-11-25 --out work/law-corpus --raw work/law-raw --workers 3
python3 scripts/fetch-law-figures.py --corpus work/law-corpus --raw work/law-raw --workers 3
python3 scripts/package-law-figures.py --corpus work/law-corpus
python3 scripts/prepare-publish-corpus.py --corpus work/law-corpus --out work/publish/law-corpus
```

e-Gov法令API Version 2を使用し、指定日の改正ID、原文XML、本則・附則・補助区分、本文の抽出件数を記録します。取得エラーがある場合は終了ステータスや `manifest.json` の `errors` を確認してください。添付資料は指定改正IDの公式APIから取得します。図表のZIPは `ZIP_STORED` 形式です。分割してもPDF自体の内容は変えません。

`--as-of` を省略すると `fetch-laws.py` は実行日を使用します。**掲載版を再取得する場合は日付を必ず指定してください。** 改正後の版に更新する場合は、データだけでなく問題・解説・用語・表示日付も確認して更新します。

### 2. 法令由来の用語辞典

```bash
python3 scripts/build-glossary.py --corpus work/law-corpus --output work/publish/glossary-data.json
```

JSON、gzip版、検証結果を生成します。語に関係する**原文の項全体**を保持し、法令・条文・附則・略称の適用範囲を区別します。`matchedText` は原文内の検索位置を示す補助情報です。定義本文や読み上げには `definitions[].text` を使います。確認できない読みは空欄であり、自動で推測して埋めていません。

### 3. 条約12資料の掲載版を再構築

```bash
python3 scripts/prepare-treaty-inputs.py --web . --raw work/treaty-raw
python3 scripts/build-treaties.py --raw work/treaty-raw --out work/publish/treaty-corpus
```

PDFは、公開ファイルにある6資料を元のSHA-256と照合して入力にします。手元にPDFがない場合は公式URLから取得し、同じハッシュを要求します。`--refresh` を付けると手元のPDFを使わず公式URLから再取得します。内容が更新されていた場合は停止し、新版の版表示や抽出方法を人が確認する必要があります。

外務省の6資料は、初回作成時に公式ページから取得した本文の行データを `scripts/inputs/treaty-web-extracts.json.gz` に保存してあります。これは**元HTMLそのものではなく、公開本文のテキスト抽出結果**です。初回作成時の直接HTTP取得では403が返る資料があり、公式ページからの本文再取得はこのスクリプトでは自動化していません。再構築では保存済み入力を復元します。版を更新する場合は公式ページの全文・条数・附属文書を再確認し、入力と版情報を更新してください。

PDFの本文抽出は `pdftotext -layout` を使用します。表紙・目次・空白ページ・説明注も物理ページとして保持します。条番号だけで分割したデータではありません。抽出順や改行はPopplerの版で変わる場合があります。条文や表の組版は収録PDFで確認してください。

### 4. 公開ファイルへ反映し、検証する

`work/publish/` 内の更新したコーパス・辞典をレビューして、公開用ファイルへ反映します。独自の問題・解説・学習用語説明も同じ版で確認してください。その後、公開用ディレクトリに対して実行します。

```bash
python3 scripts/build-offline-manifest.py --web . --version 2026.11.25.1
python3 scripts/verify-assets.py --web .
```

`dist/` を使う編集環境では `--web dist` とします。`build-offline-manifest.py` は公開ファイルのバイト数・SHA-256を計算し直して `offline-assets.json` を更新します。教材を更新したリリースでは `--version` も更新し、`sw.js` と `offline.js` のキャッシュ名を同じ値にそろえて更新してください。

`verify-assets.py` は読取専用です。公開対象ファイルの存在・サイズ・ハッシュ、42法令の件数と抽出欠落記録、図表405点のZIP形式・CRC・ハッシュ、条約12資料の区分数・出典・旧版表示、辞典の原文照合、HTMLとService Workerの依存ファイルを確認します。問題の法的妥当性、音声の発音、画面操作の正しさを自動判定するものではありません。ブラウザでも一括保存後の再読み込み、機内モード、PDF、用語検索、読み上げ、バックアップ復元を確認してください。

### 再現性の範囲

- 指定した法令版は改正IDで追跡できますが、公式API側の修正や取得時刻の差でJSON全体がバイト単位で一致するとは限りません。原文XMLとマニフェストを併せて保存してください。
- 保存済み外務省本文からの再構築はできます。公式ページを新規に取得して同じ抽出入力へ変換する処理は同梱していません。
- PDFの再構築は、収録版と同じPDF、Poppler、`pypdf` に依存します。最新版への自動更新は行いません。
- 画像のデザイン、独自の問題・解説・学習用語説明は収録ファイルが編集元です。同じ内容を外部APIから再生成する手順はありません。
- 収録数の検証値は現在の42法令・12資料・405点を前提にしています。対象を増減した場合は検証スクリプトとREADMEの数値も更新してください。

## GitHub Pagesへ公開する

GitHub Pagesの公開元を `main` ブランチの `/ (root)` に設定します。`index.html`、JavaScript、CSS、各コーパス、`offline-assets.json`、`sw.js`、`.nojekyll` をリポジトリ直下の構成でコミットします。`main` の更新後、Pagesのデプロイ完了を確認し、公開URLで動作を確認します。専用のサーバーやバックエンド処理は必要ありません。

`work/` の作業用XML、取得途中の添付資料、検証用の一時ファイルは公開成果物ではありません。公開用コーパスはそれぞれの `manifest.json` の `files` に列挙されたファイルを使用します。図表の分割片を省くと、その図表はオフラインで開けなくなります。

- [WIPOの利用条件](https://www.wipo.int/en/web/abc/tools/disclaim) と各PDF内の権利・利用条件：資料ごとの表示を確認してください。全ての版に同一のライセンスが付くとは限りません。

出典の表示や収録原本にある機関名・標章は、本サイトの推薦・公認・提携を示すものではありません。このREADMEで、第三者資料の所有権や、リポジトリ全体に対する新たな一括ライセンスを設定していません。資料を再配布する際も、個々の出典と条件を保持してください。
