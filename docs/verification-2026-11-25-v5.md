# Version 2026.11.25.5 検証記録

## 更新内容

本文を覆っていた濃緑色の大きな音声パネルを、白を基調とした小さな再生バーへ変更した。音量・速度・連続・ループ設定は「音量・設定」を押したときだけ共通dialogに表示する。枠外・閉じる・「本文に戻る」・Escで閉じても読み上げは継続する。

「小さく」（狭い画面では縮小アイコン）で右下のミニプレイヤーへ切り替え、「操作を表示」で戻せる。縮小中も一時停止・再開・停止ができ、次項目へ進んでも縮小状態を保持する。停止時にはプレイヤーと音声設定だけを閉じる。用語辞典や確認画面は閉じない。新しい読み上げは通常バーから開始する。
